# 📦 课程配套资料与会员权益

## 🎯 课程目录

课程 8 章系统讲解 MaxKB 的工程化落地：

1. MaxKB 概述与企业 AI 转型趋势
2. 核心架构：LLM + 知识库 + Agent
3. 环境搭建与开发工具链
4. 知识库构建：文档加载、切片、向量化
5. 工作流设计：函数调用、工具集成
6. Agent 编排：多轮对话、任务分解
7. 5 大场景项目实战
8. 项目部署、监控与运维

## 💎 会员权益

- 🆓 **体验会员**：免费查看 8 章课程大纲 + 5 大场景介绍
- 💎 **标准会员**：完整 60 页 PPT + 8 章节讲义 + 配套源码
- 👑 **旗舰会员**：标准会员全部权益 + 1V1 答疑 + 项目实战辅导

## 🔧 5 大场景模板

课程覆盖以下 5 个高价值场景，每个场景有专属 Prompt 模板 + 工作流示例 + 部署脚本：

1. **高校 / 机构客服** — 招生 / 选课 / 政策答疑
2. **教师备课助手** — 学科知识库 + 出题 / 答疑
3. **科研文献精读** — RAG 检索 + 摘要 + 对比阅读
4. **企业内部知识库** — 多源文档接入 + 权限隔离
5. **政务 / 公共服务问答** — 合规审批 + 数据本地化
