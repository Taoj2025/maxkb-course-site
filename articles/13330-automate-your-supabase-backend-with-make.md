# 使用 Make 自动化 Supabase 后端：教学指南

亲爱的同学们和老师们，

今天，我们将探索如何利用 **Make** 这一强大的自动化工具，来简化 **Supabase** 后端的部署与开发。这对于我们 **MaxKB FDE（前端部署开发工程师）** 培训课程的学生和教师来说，是一个非常实用的技能。

## 什么是 Supabase 和 Make？

**Supabase** 是一个开源的 Firebase 替代方案，提供了数据库、身份验证、存储和边缘函数等功能。而 **Make** 是一个自动化平台，允许你将不同的应用和服务连接起来，创建自动化的工作流程。

## 为什么要在教学中使用它们？

在我们的 **MaxKB FDE** 培训中，学生需要掌握如何高效地管理后端服务。通过结合 Supabase 和 Make，学生可以学习到如何自动化数据库操作、边缘函数调用以及日志管理等任务。这不仅提高了开发效率，还让学生在实际操作中理解自动化流程的重要性。

## 如何在教学中应用？

### 学生学习步骤：

1. **设置 Supabase 项目**：首先，学生需要在 Supabase 上创建一个项目，熟悉其基本功能，如数据库和边缘函数。
2. **连接 Make**：使用 OAuth 将 Supabase 连接到 Make。这一步可以让学生了解如何在不同平台之间建立安全的连接。
3. **创建自动化场景**：引导学生创建自动化工作流程，例如自动备份数据库、触发边缘函数或生成日志报告。
4. **测试与优化**：通过测试这些自动化流程，学生可以发现并解决潜在的问题，优化工作流程。

### 教师教学建议：

- **演示案例**：在课堂上，教师可以演示一个完整的自动化案例，帮助学生理解整个流程。
- **分组实践**：将学生分成小组，每组负责一个特定的自动化任务，最后进行成果展示和讨论。
- **结合 MaxKB 教学**：在 **MaxKB FDE** 课程中，可以将 Supabase 和 Make 的知识与前端部署的实际项目结合，让学生体验从后端到前端的完整开发流程。

## 总结

通过将 Supabase 和 Make 结合使用，学生可以掌握现代开发中不可或缺的自动化技能。这不仅提升了他们的技术能力，也为未来的职业发展打下了坚实的基础。
