## 🛤️ 3 条主流转岗路径

### 路径 1：传统前端 → AI 前端工程师（6-12 个月）
- **第 1-3 个月**：学 Prompt 工程 + LLM 基础
- **第 4-6 个月**：学 Function Calling + RAG
- **第 7-9 个月**：学 MCP 协议 + Agent 开发
- **第 10-12 个月**：做 2-3 个 AI 前端作品，投简历

### 路径 2：后端 → 全栈 + Edge（3-6 个月）
- **第 1 个月**：学 Next.js / Nuxt
- **第 2-3 个月**：学 Hono / tRPC / Drizzle
- **第 4-5 个月**：学 Edge Runtime + Cloudflare Workers
- **第 6 个月**：做 1 个全栈 SaaS 作品

### 路径 3：初级前端 → 前端架构师（2-3 年）
- **Year 1**：深耕 1 个框架 + 1 个构建工具
- **Year 2**：主导 1 个中型项目（DAU > 1 万）
- **Year 3**：写 3 篇技术文章 / 1 次技术分享

## 🔥 招聘需求 TOP 5 公司类型

1. **AI 创业公司**（月之暗面、智谱、深度求索等）- 招 AI 前端最多
2. **大厂 AI 部门**（阿里通义、字节豆包、百度文心）- 全栈 + AI
3. **跨境 SaaS**（Notion / Figma / Linear 中国团队）- Edge + 全栈
4. **金融科技**（蚂蚁、京东金融、微众银行）- 性能优化专家
5. **企业服务**（飞书、钉钉、企业微信）- 跨端 + 协作

## 💡 给小陶老师学生的 5 个建议

1. **不要只学 React**：还要学 Hono / Astro / SvelteKit（差异化）
2. **必须会 TypeScript**：90% 的高薪岗位要求 TS
3. **做一个 AI 作品**：哪怕是 AI 改简历工具，也能加分
4. **写技术博客**：面试时加分项
5. **关注开源**：给知名项目（Vercel、Cloudflare）提 PR 是最强背书
