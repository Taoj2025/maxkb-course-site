# 👨‍🏫 教师如何用 MaxKB 备课

## 📚 教师备课痛点

- 每周备课 10+ 小时，重复劳动
- 学生提问同质化，需要重复回答
- 新教师上手慢，缺乏知识沉淀
- 教研资料散落各平台，难整合

## 🎯 MaxKB 教师备课 5 步法

### Step 1：构建学科知识库（30 分钟）

- 导入教材 PDF / Word（MaxKB 自动切片）
- 导入历年试题 / 答案
- 导入教学大纲 / 课程标准
- 导入您的备课笔记 / 教学反思

### Step 2：配置智能答疑机器人（10 分钟）

设置系统提示词：

```
你是「Python 数据分析」课程的 AI 助教。
当学生提问时：
1. 优先从知识库检索答案
2. 用通俗易懂的语言 + 代码示例
3. 如知识库没有答案，诚实告知并引导提问
```

### Step 3：课前生成教学设计（5 分钟）

用 Agent 工作流：输入教学目标 + 学情，输出教学流程 + 案例 + 练习题。

### Step 4：课中实时互动

学生扫码加入答疑群，MaxKB 自动回复基础问题。

### Step 5：课后作业批改辅助

用 MaxKB 批改客观题与相似度比对，主观题仍由教师本人评判。
