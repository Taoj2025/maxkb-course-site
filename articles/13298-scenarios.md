# 📚 MaxKB 5 大场景实战模板

本课程覆盖 5 个高价值落地场景，每个场景有专属 Prompt 模板 + 工作流示例 + 部署脚本。具体效果因项目背景与投入度而异，请根据实际场景评估。

## 场景 1：高校 / 培训机构客服

**典型场景**：招生 / 选课 / 政策答疑，常见 FAQ 一键归口。

**课程提供**：FAQ 文档模板 · Prompt 模板 · 工作流示例 · Docker 部署脚本。

## 场景 2：教师备课助手

**典型场景**：学科知识库 + 出题 / 答疑 / 学情分析。

**课程提供**：教学大纲模板 · 出题 Prompt · 学科知识库搭建示例。

## 场景 3：科研文献精读

**典型场景**：RAG 检索 + 摘要 + 对比阅读。

**课程提供**：PDF 解析配置 · 检索模板 · 摘要 Prompt。

## 场景 4：企业内部知识库

**典型场景**：多源文档接入 · 权限隔离 · 内部问答。

**课程提供**：多源接入示例 · 权限配置 · 审计日志方案。

## 场景 5：政务 / 公共服务问答

**典型场景**：合规审批路径 · 数据本地化 · 私有部署。

**课程提供**：合规清单 · 私有部署脚本 · 数据本地化配置。
