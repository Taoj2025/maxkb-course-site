第 1 章 · AI 概述与数学基础

核心要点：AI 四大浪潮（符号主义→统计学习→深度学习→大模型时代）；数学三大基石（线性代数、微积分、概率论）。

关键公式：矩阵乘法 $A \cdot B$、梯度 $ abla f$、贝叶斯 $P(A|B) = \frac{P(B|A)P(A)}{P(B)}$

学习路径：吴恩达 ML 课程 → 周志华《机器学习》→ 复现经典算法

图 1-1 · AI 发展四大浪潮时间线

📝 PyTorch 矩阵运算与自动微分最小示例
import torch
x = torch.tensor([[1.0, 2.0], [3.0, 4.0]], requires_grad=True)
y = (x ** 2).sum() # y = x1² + x2² + x3² + x4²
y.backward() # 自动求导：∂y/∂x = 2x
print(x.grad) # tensor([[2., 4.], [6., 8.]])

第 2 章 · 全连接神经网络（MLP）

核心要点：感知机→MLP→反向传播算法（链式法则）；激活函数对比（Sigmoid/ReLU/Tanh）；优化器演进（SGD→Adam）。

关键公式：前向 $y = \sigma(Wx + b)$；反向 $\frac{\partial L}{\partial W} = \frac{\partial L}{\partial y} \cdot \frac{\partial y}{\partial W}$

学习路径：手写 MLP → 调参对比 → MNIST 98%

图 2-1 · MLP 架构（784→128→64→10）+ 双向数据流

📝 MLP 手写实现（PyTorch nn.Module）
class MLP(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.net = torch.nn.Sequential(
            torch.nn.Linear(784, 128), torch.nn.ReLU(),
            torch.nn.Linear(128, 64), torch.nn.ReLU(),
            torch.nn.Linear(64, 10)
        )
    def forward(self, x):
        return self.net(x.view(-1, 784))
📅 学习节奏 · 第 3-4 周 12 学时 → 第 4 周末完成 实验 2 MNIST ≥ 97%

第 3 章 · CNN 卷积神经网络

核心要点：卷积操作（局部连接+权值共享）；池化层（最大/平均）；经典架构演进（LeNet→AlexNet→VGG→GoogLeNet→ResNet）。

关键公式：卷积 $(f * g)[i,j] = \sum_{m,n} f[m,n] g[i-m, j-n]$；感受野

学习路径：CS231n → 复现 ResNet → 迁移学习

图 3-1 · 卷积运算示意（局部连接 + 权值共享两个核心特性）

📝 CNN 最小实现（CIFAR-10 分类）
class CNN(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = torch.nn.Conv2d(3, 32, 3, padding=1) # 32×32×32
        self.pool = torch.nn.MaxPool2d(2, 2)         # 32→16→8→4
        self.conv2 = torch.nn.Conv2d(32, 64, 3, padding=1)
        self.fc = torch.nn.Linear(64 * 8 * 8, 10)

第 4 章 · ResNet 与现代 CNN

核心要点：残差连接 $F(x) + x$ 解决梯度消失；BatchNorm 加速收敛；ResNet-18/50/101 对比；EfficientNet 复合缩放。

关键公式：$y = F(x, \{W_i\}) + x$；梯度 $\frac{\partial}{\partial x} = 1 + \frac{\partial F}{\partial x}$

学习路径：阅读 ResNet 论文 → 实现 50 层 → 迁移到 CIFAR-10

图 4-1 · 残差块结构（红色虚线 = 跳跃连接 · 解决深度网络梯度消失）

📝 ResNet 残差块实现
class ResidualBlock(torch.nn.Module):
    def __init__(self, in_c, out_c, stride=1):
        super().__init__()
        self.conv = torch.nn.Sequential(
            torch.nn.Conv2d(in_c, out_c, 3, stride, 1),
            torch.nn.BatchNorm2d(out_c), torch.nn.ReLU(),
            torch.nn.Conv2d(out_c, out_c, 3, 1, 1),
            torch.nn.BatchNorm2d(out_c)
        )
        self.shortcut = torch.nn.Sequential() # x 恒等映射
    def forward(self, x):
        return torch.nn.functional.relu(self.conv(x) + self.shortcut(x))

第 5 章 · RNN / LSTM 时序建模

核心要点：循环神经网络（序列建模）；LSTM 三门控（遗忘/输入/输出）解决长期依赖；GRU 简化版；双向 RNN。

关键公式：$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$

学习路径：手写 RNN → LSTM → 情感分析

图 5-1 · LSTM 时间展开图 · 三门控 × 水平细胞状态（长记忆通道）

📝 LSTM 情感分类器（IMDB）
class LSTMClassifier(torch.nn.Module):
    def __init__(self, vocab_size, embed_dim=128, hidden=128):
        super().__init__()
        self.embed = torch.nn.Embedding(vocab_size, embed_dim)
        self.lstm = torch.nn.LSTM(embed_dim, hidden, batch_first=True)
        self.fc = torch.nn.Linear(hidden, 2)
    def forward(self, x):
        _, (h, _) = self.lstm(self.embed(x))
        return self.fc(h.squeeze(0))

第 6 章 · Transformer 注意力机制

核心要点：Self-Attention（QKV 三矩阵）；Multi-Head（多视角并行）；Positional Encoding（位置信息）；LayerNorm。

关键公式：$\text{Attention}(Q,K,V) = \text{softmax}(\frac{QK^T}{\sqrt{d_k}})V$

学习路径：Attention Is All You Need 精读 → 实现 Self-Attention → 多头

图 6-1 · Self-Attention 计算图（Q/K/V 三矩阵 → 相似度 → 权重 → 加权求和）

📝 Multi-Head Attention 核心
class MultiHeadAttention(torch.nn.Module):
    def __init__(self, d_model, n_head=8):
        super().__init__()
        self.n_head = n_head
        self.qkv = torch.nn.Linear(d_model, d_model * 3)
        self.proj = torch.nn.Linear(d_model, d_model)
    def forward(self, x):
        B, N, C = x.shape
        qkv = self.qkv(x).reshape(B, N, 3, self.n_head, C // self.n_head)
        q, k, v = qkv.permute(2, 0, 3, 1, 4)
        attn = (q @ k.transpose(-2, -1)) * (C ** -0.5)
        attn = attn.softmax(dim=-1) @ v
        return self.proj(attn.transpose(1, 2).reshape(B, N, C))

第 8 章 · 生成模型（GAN / VAE / 扩散）

核心要点：GAN 对抗训练（生成器 vs 判别器）；VAE 变分自编码器（隐空间）；Stable Diffusion 潜在扩散模型。

关键公式：$\min_G \max_D V(D,G) = \mathbb{E}[\log D(x)] + \mathbb{E}[\log(1-D(G(z)))]$

学习路径：手写 DCGAN → 调参生成人脸 → 扩散模型

📝 DCGAN 最小实现（生成手写数字）
class Generator(torch.nn.Module):
    def __init__(self, z_dim=100):
        super().__init__()
        self.net = torch.nn.Sequential(
            torch.nn.ConvTranspose2d(z_dim, 128, 4, 1, 0), torch.nn.BatchNorm2d(128), torch.nn.ReLU(),
